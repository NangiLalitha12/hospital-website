This repository contains the source for the Medical Oasis Online hospital website (Vite + React + TypeScript + Tailwind CSS).

Quick start

1. Install dependencies

```powershell
npm i
```

2. Run development server

```powershell
npm run dev
```

If you need documentation or help running the project locally, contact Lalitha Nangi.
